## 💡 Tips for Beginners

1. **Don't skip files** — each one builds on the last
2. **Type the code yourself** — don't just copy-paste
3. **Run every example** — see the output with your own eyes
4. **Make mistakes** — errors are your best teachers
5. **Try the tasks** before looking at solutions
